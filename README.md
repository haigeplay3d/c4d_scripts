# Haige C4D Scripts

13 个用于日常 Cinema 4D 工作流的 Python 脚本，统一使用 **HG_** 前缀，便于在命令搜索中查找。

- [脚本总表与使用说明](docs/script-catalog.md)
- [安装与运行](docs/installation.md)
- [图标使用说明](docs/icons.md)

## 快速使用

1. 下载项目，将需要的工具目录放入自己的 C4D 脚本目录；保留 `.py` 与同名 `.tif` 相邻。
2. 在 Script Manager（脚本管理器）中打开 `HG_*.py`，或在脚本已被 C4D 发现后搜索 `HG_`。
3. 按工具说明选择对象再运行。首次使用请在场景副本中操作。

旧版本升级到 HG_ 名称后，已有工具栏按钮或快捷键可能需要重新关联。若仍显示旧名称，保存工作后按需重启 C4D。

## 内容

```text
c4d_scripts/       脚本、同名图标、逐项说明及示例资源
docs/              脚本总表、安装和图标说明
assets/icons/      图标总览
```

以 C4D 2025 为主要使用基线；各工具的验证范围见对应说明，不保证所有版本或所有场景均适用。个人偏好设置脚本会修改软件设置，请先阅读说明。
