# 安装与运行

## 已配置额外脚本目录的本机

本项目现有工作目录位于 `C4D_SCRIPTS_DIR` 指向的额外脚本根目录之下。保持当前位置即可，不要再把同一批脚本复制到安装目录，避免多份版本混淆。

Windows PowerShell 可只读查询系统设置：

```powershell
[Environment]::GetEnvironmentVariable('C4D_SCRIPTS_DIR', 'Machine')
```

系统变量存在不等于当前 C4D 进程已继承它。若新改过环境变量，保存工作后再自行重启 C4D；不要为了整理文档关闭现有会话。

## 其他电脑

将所需工具的完整目录放到自己管理的脚本位置，先通过 C4D 的 Script Manager（脚本管理器）打开 `.py` 并运行。配套资源保持相邻。长期使用时按目标 C4D 版本的脚本目录配置方式加入搜索路径，再验证菜单或命令搜索能否找到工具。

首次运行使用场景副本，并阅读工具 README 的作用范围。个人偏好设置脚本修改软件设置，应单独检查原设置与恢复方式。

## 验证边界

本轮仅核对本地系统变量和文件组织；没有重新验证 C4D 菜单发现、图标显示、快捷键或各脚本的实际运行。
