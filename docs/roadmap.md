# 100 个 C4D 脚本开发路线

## 当前基线

13 个已开发工具已列入总表。100 是长期目标，不以复制变体或空目录凑数；清单编号与文件名分离。剩余数量不代表已批准的 87 项需求。

## 阶段安排

1. **项目整理（本轮）**：保留源文件位置，补齐总表、使用说明、安装说明和问题清单。
2. **已有工具加固**：按质量清单集中修复与验收，每批 2–3 个；先处理零尺寸、按键失败、撤销与大范围操作。
3. **下一批需求**：从真实制作中收集候选，先记录重复劳动、输入、输出、适用对象和已有替代工具，再确定开发顺序。
4. **逐批交付**：每个工具具备说明、恢复方案、目标版本与宿主验收记录后，再记录发布版本。
