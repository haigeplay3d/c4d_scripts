# 按目标尺寸等比缩放（FigureScale）

## 使用

只选中一个对象，修改 SourceX、SourceY 或 SourceZ 中一个值后确认；以最后编辑的轴为准。取消或不改值不执行。

在 C4D Script Manager（脚本管理器）运行同目录 `FigureScale.py`。首次使用在场景副本中操作。

## 行为与边界

当前尺寸按本地包围盒轴在世界空间的长度计算，计入对象、冻结及父级变换的轴长度。它不是世界轴对齐包围盒，也不是变形缓存或整个子层级的最终尺寸。

只用所编辑轴计算统一缩放比例，因此平面可以通过非零轴缩放；被编辑轴为零、目标非正数或非有限值时拒绝执行。保留镜像缩放符号，新增一次操作的撤销登记。
