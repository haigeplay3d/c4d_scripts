# 坐标与角度取整（RoundXYZ）

## 使用

选择对象。默认处理坐标；Alt 仅处理角度；Shift 同时处理坐标和角度；Shift 与 Alt 同按时按 Shift。

在 C4D Script Manager（脚本管理器）运行同目录 `HG_RoundXYZ.py`。首次使用在场景副本中操作。

## 行为与边界

位置取整数，角度保留一位小数；保留原有 GetAbsPos/GetAbsRot 坐标语义，不改为世界矩阵操作。Python round 在正好一半时采用就近偶数规则。

键盘状态读取失败时按无修饰键处理。异常路径确保结束撤销组；保留整批操作撤销登记。
