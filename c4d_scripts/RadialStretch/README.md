# RadialStretch — 一键径向拉伸

给可编辑圆环自动添加原生 Formula（公式）变形器和中文控制标签。自动测量原始内外半径，后续只调滑块，无需手算或改公式。

## 使用

1. 选中一个可编辑的完整圆环；圆环须位于**对象局部 XZ 平面**，Y 是厚度方向。
2. 在 C4D 脚本管理器打开并执行 `HG_RadialStretch.py`，或从已配置的脚本目录调用它。
3. 脚本自动选中新增的 **径向拉伸控制** Python 标签；在属性管理器点击 **User Data（用户数据）**。
4. 调整 **内圈偏移 / 外圈偏移 / 整体强度**。

| 参数 | 含义 |
| --- | --- |
| 内圈偏移 | 正数扩大洞口，负数缩小洞口；0 保持内圈不动 |
| 外圈偏移 | 正数扩大外轮廓，负数收缩外轮廓；0 保持外圈不动 |
| 整体强度 | 0% 为原形，100% 为设定偏移量；可打关键帧 |
| 重新读取原始半径 | 修改基础模型后重新测量原始点；保留偏移与强度，支持撤销 |

例如：内圈偏移 0、外圈偏移 10 cm、强度 100%，表示内圈固定、外半径扩大 10 cm，外直径扩大 20 cm。

添加时偏移均为0，保持原形。重复执行只选中已有控制标签，不重复添加或重置参数。内外圈偏移也可打关键帧。

## 模型要求与边界

- 当前版本针对完整、同心、近似圆形的多边形圆环。不是任意轮廓的拓扑边缘识别工具；没有自动识别 XY/YZ 平面。
- 对象轴可以偏离圆心：脚本按原始点的局部 XZ 包围盒中心对齐变形器。对象本身在世界空间旋转或移动不影响此约定。
- 输入尺寸是对象局部长度；对象或父级缩放会进一步影响世界空间的最终尺寸。
- 未自动转换参数对象、生成器、实例或克隆。请在副本上转为可编辑对象后使用。
- 对象已有启用的变形器时，会提示而不叠加创建。细分曲面可以放在圆环的父级，让径向拉伸在细分之前计算。
- 只读取原始点，不写入点坐标，也不从变形结果反复测量，所以不会逐帧累积变形。
- 若调整导致内半径不大于0、或外半径不大于内半径，将恢复原形并显示范围错误；改回有效参数即恢复。
- 不要手动移动、旋转或缩放生成的公式变形器；误改时点击“重新读取原始半径”恢复对齐。公式、Effect 和 Size 由控制标签管理；无需点击 Fit to Parent。
- 可继续添加 Fields 做局部权重，但面板目标尺寸是在域权重为100%时的值。

## 保存与撤销

控制代码和基准尺寸完整保存在 Python 标签内，随 `.c4d` 文件保存。打开该场景不需要本脚本文件，但需要 C4D 允许执行场景中的 Python 标签。

添加支持一次 Ctrl+Z 撤销、重做。按钮重读也有独立撤销记录。移除工具时移除新建的“径向拉伸”变形器及其控制标签即可；原始模型点不变。

## 验证

2026-09-23，Cinema 4D **2025.3.3** 宿主验证通过：

- 原生 Formula 创建；内外偏移、组合偏移、半强度/零强度；连续求值无累积。
- 重复添加、无效半径恢复、重新读取按钮、保存重开后继续调整。
- 添加撤销/重做、偏心局部轴、世界位移/旋转/缩放、不支持类型和已有变形器的拒绝路径。
- 实际3936点圆环模型的全点径向及厚度误差低于 `3e-14 cm`。
- 使用C4D原生属性控件，界面实机检查中文参数与按钮。

其他 C4D 版本、任意非同心形状、复杂变形器堆栈、渲染农场尚未验证。

## 实现说明

采用原生 Cylindrical Formula，Size 固定为三轴200 cm，内部处理归一化坐标。标签只更新参数，按钮在主线程响应并登记撤销；求值函数不创建/删除对象、不改时间、不读写外部文件。

参考：[Maxon 线程规则](https://developers.maxon.net/docs/py/25_113/manuals/application_development/threading.html)、[用户数据按钮的GUI设置](https://developers.maxon.net/forum/topic/13902/how-to-add-button-user-data-with-a-button-gui-in-python-script/2)。
