# 平面宽高比例锁定（PlaneLockRatio）

添加同名 Python 标签，持续联动平面宽高。

## 使用

1. 选中一个参数化 Plane 对象。
2. 在 C4D 脚本管理器运行同目录的 `PlaneLockRatio.py`。
3. 检查结果；首次使用请在场景副本中操作。

## 范围与恢复

未显式登记撤销；已有同名标签时退出；零宽高和保存重开后的基准需验证。
