# 复制世界变换（PositionWorldFollow）

一次性复制完整世界矩阵，包含位置、旋转和缩放；不是持续跟随。

## 使用

1. 按顺序选择至少两个对象；使用最后两个，前者为来源、后者为目标。
2. 在 C4D 脚本管理器运行同目录的 `PositionWorldFollow.py`。
3. 检查结果；首次使用请在场景副本中操作。
