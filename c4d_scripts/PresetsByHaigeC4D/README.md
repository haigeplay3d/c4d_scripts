# 个人 C4D 偏好设置（presetsbyhaigec4d）

修改界面、视图、文件、撤销深度、通讯、材质和导入等软件偏好。

## 使用

1. 确认希望采用脚本内列出的个人偏好，先检查源码设置项。
2. 在 C4D 脚本管理器运行同目录的 `HG_presetsbyhaigec4d.py`。
3. 检查结果；首次使用请在场景副本中操作。
