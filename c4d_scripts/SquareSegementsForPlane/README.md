# 平面近似正方形分段（SquareSegementsForPlane）

添加同名 Python 标签，根据宽高与分段数联动另一方向的分段数。

## 使用

1. 选中一个参数化 Plane 对象。
2. 在 C4D 脚本管理器运行同目录的 `HG_SquareSegementsForPlane.py`。
3. 检查结果；首次使用请在场景副本中操作。

## 范围与恢复

未显式登记撤销；整数取整使网格仅近似正方形；零尺寸需复查，保留历史 Segements 拼写。
