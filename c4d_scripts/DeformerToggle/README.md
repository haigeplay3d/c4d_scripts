# 切换变形器编辑器可见性（DeformerToggle）

切换变形器的编辑器可见性参数；不是修改 Basic Enabled。

## 使用

1. 选中对象或层级根，查找其内部预设类型列表中的变形器。
2. 在 C4D 脚本管理器运行同目录的 `DeformerToggle.py`。
3. 检查结果；首次使用请在场景副本中操作。

## 范围与恢复

未显式登记撤销；父子同时选中可能重复处理，实际变形开关效果需在宿主核实。
