# 随机标准材质颜色（RandomColorStandardMaterial）

修改已有首个纹理标签的标准材质颜色，或创建标准材质并设置纹理标签。

## 使用

1. 选中对象；选择读取包含子级。
2. 在 C4D 脚本管理器运行同目录的 `RandomColorStandardMaterial.py`。
3. 检查结果；首次使用请在场景副本中操作。

## 范围与恢复

未显式登记撤销；共享材质会影响其他使用者，非标准材质引用可能被替换。
