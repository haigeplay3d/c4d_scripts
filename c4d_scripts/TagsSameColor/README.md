# 对象与标签随层着色（TagsSameColor）

添加 Python 标签，持续将图层颜色写到对象图标和各标签图标。

## 使用

1. 选中一个已分配图层的对象。
2. 在 C4D 脚本管理器运行同目录的 `HG_TagsSameColor.py`。
3. 检查结果；首次使用请在场景副本中操作。

## 范围与恢复

未显式登记撤销；移除控制标签会停止驱动，但不会自动还原之前的颜色。
