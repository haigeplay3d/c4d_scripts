# 删除空对象并保留子级（DeleteNulls）

## 使用

选中待处理对象或层级根；递归处理其下 Null，包含有子对象的 Null。

在 C4D Script Manager（脚本管理器）运行同目录 `DeleteNulls.py`。首次使用在场景副本中操作。

## 行为与边界

子对象提升到被删除 Null 所在层级，保持兄弟顺序并回写世界矩阵。父子同时选中时仅处理最上层选中根，避免重复访问已删除对象。使用层级与 PSR 撤销登记，并确保结束撤销组。

这不是仅删除“无子级 Null”的工具。删除 Null 可能影响绑定、约束或外部链接；它们不在本轮修复范围。复杂非均匀缩放叠加旋转形成的剪切、动画和驱动场景需要独立实测，不能保证任意矩阵分解都无损。
