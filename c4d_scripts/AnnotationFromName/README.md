# 对象名称注释（AnnotationFromName）

创建或更新 ForAnnotation 和 ForName 标签，将对象名称持续同步到注释。

## 使用

1. 选中需要显示名称的对象；选择读取包含子级。
2. 在 C4D 脚本管理器运行同目录的 `HG_AnnotationFromName.py`。
3. 检查结果；首次使用请在场景副本中操作。

## 范围与恢复

未显式登记撤销；重复运行会重写同名控制标签代码。
